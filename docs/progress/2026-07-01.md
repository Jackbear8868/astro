# 進度紀錄 2026-07-01

## 1. 資料來源
Haro11 的 MUSE cube(WFM-NOAO-E,499×559×3679):
- `Haro11_wsky.fits` — **含天空**(還沒扣)。
- `Haro11_nosky.fits` — MUSE pipeline **已扣天空**,當作 ground truth 真值。
- 另有 NFM-AO 版本(高解析、窄視野),本階段主要用 WFM。

## 2. 完成 nosky 與 wsky 的 ZAP 對照(整張視場)
兩者用**完全相同的參數**(只換輸入 cube),各約 66 分鐘跑完整張 499×559。

| | wsky 原始 | wsky+ZAP | nosky 原始(真值) | nosky+ZAP |
|---|---|---|---|---|
| 天空線 5577Å 中位殘餘 | 252.7 | 0.62 | 2.30 | 0.69 |
| line-free 雜訊/spaxel | 3.58 | 6.68 | 2.65 | ~86 |
| 源 Hα | (含天空) | 保留 124% | 100%(基準) | 扭曲 ~5× |

- **`wsky+ZAP`**:天空線壓到 ~0,還原 MUSE 扣天空且保留源 → 有效。
- **`nosky+ZAP`**:已無天空可扣,ZAP 反而注入雜訊、扭曲源(對照組 / null test)。
- 結論:**ZAP 必須輸入「還含天空」的 cube 才有效**,與參數調整無關。

產出:`results/zap/`(fig5 主驗證、fig8 基準、fig9 四者疊圖、fig1–3 null test);腳本 `src/compare_4way.py`。
