========================================================================
ZAP 2×2 實驗 — RUN PLAN
========================================================================
目標:比較「ZAP 對象(nosky/wsky)」×「source-mask 來源(nosky/wsky)」。
      方法固定 sep(SEP + matched filter + 2σ)。nosky / wsky 同等對待。

原始輸入(唯讀,永不刪):
    data/Haro11_nosky.fits
    data/Haro11_wsky.fits

產物結構(將清空 results/zap/ 重建):
    results/zap/masks/<method>_from-<cube>/   (method 預設 sep；對照 claude。每組各自一資料夾,不覆蓋)
        mask.fits      source mask(= segmentation mask)
        blanks.npz     亮源座標(sy,sx) + 取樣 blank + 波長軸
    results/zap/cubes/<target>_maskfrom-<src>/
        zap.fits      扣天空後的 cube (DATA + STAT;STAT 為原始照抄)
        sky.fits      ZAP 學到並扣掉的天空
        var.fits      ZAP 的逐波長變異曲線(診斷用)

========================================================================
STEP 1 — 建 source / segmentation mask(便宜,~1 分鐘/次)
========================================================================
跑 2 次(從 nosky、從 wsky 各建一張):

    python src/0706/step1_mask.py nosky
    python src/0706/step1_mask.py wsky

  讀: data/Haro11_<src>.fits         (只用 DATA HDU)
  寫: results/zap/masks/<method>_from-<src>/mask.fits
      results/zap/masks/<method>_from-<src>/blanks.npz

========================================================================
STEP 2 — ZAP(貴,~33 分鐘/次;共 4 次 ≈ 2.2 小時)
========================================================================
語法: step2_zap.py <target> <mask_from> [--ncpu N]

    (1)  python src/0706/step2_zap.py wsky  nosky --ncpu 16
    (2)  python src/0706/step2_zap.py wsky  wsky  --ncpu 16
    (3)  python src/0706/step2_zap.py nosky nosky --ncpu 16
    (4)  python src/0706/step2_zap.py nosky wsky  --ncpu 16

  讀: data/Haro11_<target>.fits                        (DATA + STAT)
      results/zap/masks/sep_from-<mask_from>/mask.fits (mask= 參數)
  寫: results/zap/cubes/<target>_maskfrom-<mask_from>/{zap,sky,var}.fits
  ⚠ 需要改程式:目前 step2 CLI 只吃 <target>、固定用 nosky-mask、輸出固定 <cube>_zap.fits。

  2×2 對照:
                 mask 來源 nosky      mask 來源 wsky
    ZAP wsky        (1)                  (2)
    ZAP nosky       (3)                  (4)
