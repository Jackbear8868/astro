# Data 建立策略:資料來源、ML 角色、評估指標(sky reconstruction)

> 本檔回答「訓練/評估的 data 要怎麼建、用什麼尺量」。先盤點 6 篇論文怎麼建 GT、用什麼資料,再分析我們(MUSE IFU)能用哪些、怎麼排序、怎麼呈現效果。
> 搭配主計畫 [`predict-sky-implementation-plan.md`](predict-sky-implementation-plan.md)。北極星不變:我們做 **sky reconstruction(建天空本身)**。

---

## 0. 核心觀念

### 0.1 沒有人有「天體底下的真天空」
這是整題的物理現實 —— **永遠量不到「某個天體正下方、那一刻的真天空」**,因為天體擋在那裡。所以「GT」有三種不同身分,別混為一談:
1. **訓練用 GT**:多數方法(PCA / NMF)是 **unsupervised**,訓練不需要 GT,只要「一堆只有天空的光譜」學基底。GT 只在評估登場。少數 supervised(SMI 偽標籤、Rhea NN 回歸係數)的標籤也都來自**只有天空的區域**。
2. **評估用 GT**:靠「只有天空的區域」(sky fiber / blank spaxel),那裡觀測**就等於**天空。
3. **「天體底下」GT**:唯一辦法是**模擬 / 注入**(自己合成已知天空)。真實資料給不出。

### 0.2 兩個不同的軸(重要,別混)
- **軸一|資料從哪來(材料)= A、B、C**。這三個才是真正的「data 來源」。
- **軸二|沒有 GT 時怎麼評分(尺)= D**。**D 是一組 metric(評分準則),不是資料。**

> 比喻:**A/B/C 是「你拿什麼材料」,D 是「你拿什麼尺去量」。** 尺能量任何材料 —— 你可以在真實 blank(A)、注入(B)、mock(C)、甚至原始真實資料上都套同一把 D 尺。所以 D 不是 A/B/C 的對等選項,而是**疊在它們上面**。

## 1. 我們的 data(MUSE IFU)vs 其他兩種

| 面向 | **MUSE IFU(我們)** | 多光纖(W&H / Zhang16 / SMI) | 長狹縫(KM / Kolganov) |
|---|---|---|---|
| 結構 | datacube **(x, y, λ)**,完整 2D 空間 | N 條**離散** 1D 譜,散布在大視場 | 2D 影像 = **沿縫 1D 空間** × λ |
| 「天空樣本」 | blank spaxel,**上萬條、成片相連** | 專用 sky fiber,**稀疏**(SDSS ~32/板、LAMOST ~10/光譜儀) | 縫上沒有天體的那幾列 |
| 空間相關性 | 相鄰 spaxel 高度相關(可內插) | 點位稀疏、不連續 | 沿縫天空≈常數、天體有峰 |
| 「一筆資料」的意義 | **一個 cube = 一次曝光**,內含上萬 spaxel | 一塊板=上千光纖;且有**很多塊板**(跨曝光) | 一次曝光 = 一個天體 |
| 額外資產 | **STAT(逐 voxel 變異)**可做反變異加權;wsky/nosky 配對 | 每纖 throughput H 要歸一 | — |

**三個對我們最關鍵的差別:**
1. **空間維度**:我們是唯一有「完整 2D 連續空間」的。→ 只有我們能像 Rhea 那樣做「**座標 → 天空** 的空間內插」。這是 IFU 最大優勢,也是我們跟 5/6 篇的根本差異。
2. **天空樣本的量**:blank spaxel **又多又成片**(上萬),光纖 sky fiber 只有 ~10–32 條。**資料比他們富有。**
3. **訓練範式**:光纖巡天靠「跨很多塊板」累積大 N(SMI / W&H);我們跟 **Rhea 一樣「在單一 cube 內」學**。→ 參照組是 **Rhea**,不是 SMI。

## 2. 三個資料來源(A / B / C)

> 可行性以「工作量 / 複雜度 / 資料是否現成」評(★ 越多越容易),與硬體無關。

### 來源 A|天空主導區「就是」天空(blank spaxel / sky fiber)
- **做法**:blank spaxel 的觀測譜 = 天空樣本。
- **優**:免費、**真實**(真 LSF/OH/雜訊)、**量大**、零額外工。
- **缺**:**只在「沒有天體」處有效** → 對「天體底下」**驗不到**;觀測是「帶雜訊的天空」非乾淨天空。
- **可行性**:★★★★★(`cmd_mask()` 已抽 8000 條)。
- **需要**:好的 source mask(已有)+ 決定 train/val/test 怎麼切。

### 來源 B|注入 / 半合成(真天空 + 真乾淨天體)
- **做法**:把**已知真天空**(取自 blank spaxel)加到**已知乾淨區域**(如 nosky 的源區)→ 答案已知的測試樣本。
- **優**:有**已知答案** + 用**真實天空**(比 mock 真實);**能探到「天體底下」**;比 mock 省事。Kurtz&Mink 就是這招。
- **缺**:當底的「乾淨天體」不完美(帶殘餘);疊到源區會**重複計入雜訊**;天空不隨位置變則測不出梯度能力。
- **可行性**:★★★★(中上)。
- **需要**:乾淨底 + 真天空樣本 + 注入配方(均勻 vs 隨位置變)。

### 來源 C|全模擬 mock(從頭合成,含「天體底下」)
- **做法**:合成 cube = 已知星系 + 已知天空(SkyCalc / Cerro Paranal + MUSE LSF)+ 真實雜訊。→ **每個 spaxel(含星系底下)都有真天空**。
- **優**:**唯一能量化「天體底下」**;可控(任意調月光/梯度/OH)。
- **缺**:**最花工**;有「擬真落差」(mock 天空太簡單,贏了也沒說服力);要建 LSF + throughput + 相關雜訊。
- **可行性**:★★(中下)。
- **需要**:天空模型(已有 SkyCalc/Noll)、星系模型(可拿真實已扣天空星系當「真星系」)、MUSE LSF + 雜訊。

## 3. 評分尺 D —— metric 清單 + 怎麼呈現效果

D 不是資料,是一組評分準則(也可兼任 unsupervised 的訓練 loss:「blank 殘餘最小 + 不動源流量」就是天然 loss)。指標分三層:

### (a) Truth-free 指標(真實資料就能算;D 尺的本體)
| 指標 | 量什麼 | 越好 | 呈現方式 |
|---|---|---|---|
| **blank 殘餘 std(λ)** | 扣完 blank 是否平坦 | 低 | 線圖 std vs λ(你 vs ZAP vs baseline)← 你的 **fig2** |
| **天光線殘餘** | 5577 / 6300 / OH 8400 等位置殘餘 | 低 | 放大線圖 / 表 |
| **源流量保真** | Hα/[OIII] 扣前後不變 | 重疊 | before/after 疊圖 ← 你的 **fig3** |
| **殘餘分布** | 殘餘是否集中於 0 | mean≈0、小變異 | 直方圖(SMI 用過) |
| **噪音底比較** | 殘餘 std vs Poisson/STAT 底 | 接近 1(不過扣) | 線圖比值(W&H/KM 用過) |
| **殘餘 2D 影像** | 殘餘的空間結構 | 無相關結構 | 殘餘影像 @ 某天光線 |

### (b) GT-based 指標(需 held-out blank(A),或 B/C)
| 指標 | 量什麼 | 越好 | 呈現方式 |
|---|---|---|---|
| **重建 RMSE / MAE** | 預測天空 vs 真天空 | 低 | 對照表 / 線圖(SMI 用 MAE/RMSE) |
| **under-source 重建誤差** | **源位置**的重建誤差(需 B/C) | 低 | 對照表(**headline 數字**) |
| **bias(系統偏差)** | 平均過扣/欠扣 = mean(pred−true) | ≈0 | 表,分 blank / source 算 |
| **線 vs 連續譜分別誤差** | 錯在哪(線難扣) | 低 | 表 / 線圖 |

### (c) Downstream / 科學指標(終極驗收)
| 指標 | 量什麼 | 越好 | 呈現方式 |
|---|---|---|---|
| **回收的星系量** | 扣完後 Hα flux / kinematics 對不對 | 接近真值/參考 | flux map(Rhea 用)、kinematics 圖 |
| **S/N 改善** | 相對 baseline 提升多少 | 高 | 表 / 線圖(W&H +20%) |

### 呈現「效果」的標準套組(對應你 `results/zap/` 已有的)
1. **殘餘 std vs λ** 線圖(你的方法 / ZAP / baseline 疊一起)
2. **2D 殘餘影像** @ 某天光線(看空間結構)
3. **源譜 before/after 疊圖**(證明沒過扣)
4. **殘餘直方圖**(集中於 0)
5. **重建 RMSE 對照表**(分 blank 區 vs source 區、分各方法)← 最有力的量化
6. **差異圖**(你的天空 − baseline 天空,空間呈現)
7. **科學圖**(Hα flux map 等,終極驗收)

## 4. 「能驗天體底下」是什麼、為什麼特別

**「天體底下」= 星系/恆星所在 spaxel 位置上的天空。**

在有星系的 spaxel:觀測 = 星系 + 天空 + 雜訊,**混在一起**。要扣天空就得知道那位置的天空,但你沒法在那直接量(星系壓在上面);只能在 blank spaxel 乾淨量到天空。所以「驗天體底下」= **檢查重建的天空在星系位置上對不對**。它特別在於:

1. **它才是真正目標**:扣天空就是為了清乾淨科學光譜(星系);blank 處的天空不是最終在乎的。
2. **那裡天生沒真值**:blank 觀測=天空(有真值);星系處觀測=星系+天空,單一真實觀測**永遠拆不出**真天空。
3. **方法差異與失敗都在這**:大家在 blank 都做得好(在那學的);難在**外插/內插到量不到的位置**(星系底下,可能有梯度、LSF 不同),**過扣/欠扣**都在此發生。
4. **這正是文獻空缺 / novelty**:因為量不到真值,幾乎沒人量化它;能量化(靠 B/C)就是科學貢獻。

> **為什麼只有 B、C 驗得到**:你需要「**同時有源、又有已知天空**」的位置。真實資料給不出(blank 依定義沒源)。只有注入(B:把已知天空疊到真星系上)或 mock(C:連星系底下都有已知天空)能造出這種位置。**A 在任何資料型態上都驗不到天體底下。**

## 5. train / val / test 對應表

| 資料來源 | train(學參數) | validation(調超參/early stop) | test(最終回報) | 能驗「天體底下」? |
|---|---|---|---|---|
| **A** 真實 blank | ✓ **主要**(學基底/網路) | ✓(held-out blank,如 Rhea 1%) | ✓(另一塊 blank → 真重建 RMSE) | ✗ 永遠不行 |
| **B** 注入/半合成 | 通常不(可選) | ✓ | ✓ **可控探針** | ✓ 可以 |
| **C** mock | ✓(**唯一能給「源底下」標籤**) | ✓ | ✓ **黃金標準** | ✓ 可以 |
| **D** 評分尺 | (可當 unsupervised 的 **loss**) | 用來評分 | 用來評分 | 視所量資料而定 |

**具體例子**
- **A-train**:對 blank spaxel 擬合 PCA/NMF/autoencoder 基底。
- **A-val**:留一小撮 blank 決定「留幾個成分 / early stop」(W&H 停止準則、Rhea 1%)。
- **A-test**:另一塊(**空間分塊**的)blank,算重建 RMSE。
- **B-test**:把已知天空注入到 nosky 源區 → 看能否在「假源」底下還原。
- **C-train**:supervised 網路學「spaxel(含星系底下)→ 注入的真天空」。
- **C-test**:mock 每個 spaxel 都有真天空 → 算星系底下的精確 RMSE。

**有沒有「專門只在某一個 role」的?**
- **D**:不是 data role,是**純評分(可兼 loss)**,最特別 —— 它從來不是一份資料集。
- **B**:實務上**幾乎只當 test**(可控探針),很少 train(底不乾淨、會循環)→ 可說「專門做評估/測試」。
- **A**:**三個 role 都能**,但**只限 blank 區**(碰不到天體底下)。
- **C**:**三個 role 都能**,且是**唯一能涵蓋「天體底下」train/val/test 的**。

**一句話總結**
> 訓練資料 → 主要 **A**(真實 blank,unsupervised);要做 supervised under-source 才加 **C**(mock)。
> 評估/測試 → blank 區用 **A held-out**;天體底下用 **B(便宜探針)** 或 **C(黃金標準)**。
> 所有評估都用 **D 這把尺** 來量。

## 6. 前人怎麼被分類(資料型態 × 來源/尺 交叉表)

| | A(天空區=天空) | B(注入) | C(mock) | D(殘餘尺) |
|---|---|---|---|---|
| **IFU** | **Rhea**(背景 spaxel,99/1 held-out) | — | — | **Rhea**(差異圖,定性) |
| **多光纖** | **SMI**(sky fiber→偽標籤)、**W&H**(sky fiber 應為零) | — | **Zhang16**(LAMOST 模擬器) | **W&H、Zhang16、SMI** |
| **長狹縫** | (縫上天空列) | **Kurtz&Mink**(注入天空→還原紅移) | — | **Kolganov**(僅目視) |

**規律**:A 是普世的訓練資料來源(光纖、IFU 都用);B 只有 Kurtz&Mink(需要答案已知的紅移測試);C 只有 Zhang16(剛好有 LAMOST 模擬器);D 幾乎人人用來報結果。

## 7. 資料型態會不會「限制」能用哪個?

**結論:A/B/C/D 原則上在三種資料上都能實作,不被資料型態硬性封死。** 資料型態改變的是「資料量」與「價值/難度」:
- **A**:三種都能,**IFU 樣本最多最密**,光纖最稀疏(差在量)。
- **B**:三種都能(Kurtz&Mink 在光纖證明,我們 IFU 一樣能)。
- **C**:三種都能,**前提是建得出該儀器前向模型**;IFU 較難建但**價值最高**(唯一給 2D 天體底下真值)。
- **D**:三種都能,永遠可用。

**唯一真正被資料型態決定的**:不是策略本身,而是「**天體底下只有 B/C 驗得到**」;且 **IFU 獨有「把天空從周圍空間內插到天體底下」的能力**(光纖散點做不到)——這是 Rhea / 我們的優勢。

## 8. 推薦做法(D 永遠開著;資料來源依目標推進 A → B → C)

把 **D 當成全程開著的尺**,資料來源由淺到深建:

**① 永遠開 D(殘餘指標)**:你已有(fig2/fig3),零成本,全領域報結果的標準,每步的即時 sanity check。**必要非充分**(驗不到天體底下)。

**② 先建 A(held-out blank)**:免費、真實,給貨真價實的重建 RMSE(blank 上)。Rhea 的 99/1 做法。⚠️ 切分**按空間分塊**(避相關雜訊洩漏)。

**③ 再加 B(注入)**:A 驗不到的「天體底下」,B 用真實天空可控地測,成本遠低於 C。A 跑通後做。

**④ 最後 C(mock)**:唯一能量化「天體底下」、做出乾淨 novel claim(文獻空缺)的方法。最花工、有擬真落差。**方法在 A/B 跑通、要寫 headline 數字時再做。**
