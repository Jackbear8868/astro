# B. 資料的結構（IFU / FITS 檔怎麼組成）

> 用真實檔案對照：`data/Haro11_WFM_MUSE_archive.fits`
> 結構：`PRIMARY` + `DATA` + `STAT`，DATA/STAT 維度皆 `(492, 500, 3802)`

---

## 10. Datacube（資料立方體）

MUSE 是**積分視場光譜儀 (IFU)**：它不是只拍一張照片，而是對視野裡**每一個空間位置都記錄一條完整光譜**。
結果就是一個三維陣列 —— 資料立方體：

```
                  波長 (3802)
                 ╱
                ╱
        ┌──────────────┐
   y    │              │   ← 固定某個波長 = 一張單色影像 (492 x 500)
 (500)  │   星系影像     │
        │              │   ← 固定某個 (x,y) = 一條光譜 (長度 3802)
        └──────────────┘
              x (492)
```

兩種看法（同一個 cube）：
- **沿波長切**：每一片 (slice) 是星系在某個波長的單色影像。3802 片疊起來 = cube。
- **沿空間取**：挑一個 (x,y)，把它在 3802 個波長的值串起來 = 那個位置的光譜。

你的 WFM 檔：`NAXIS1=492`、`NAXIS2=500`、`NAXIS3=3802`
→ 空間 492 × 500 個格子，每格一條長度 3802 的光譜。

⚠️ **座標軸順序陷阱**：FITS header 寫 (NAXIS1, NAXIS2, NAXIS3) = (x, y, 波長)；
但用 astropy 讀進 numpy 後，array.shape 是**反過來**的 `(3802, 500, 492)` = (波長, y, x)。
取一條光譜要寫 `cube[:, y, x]`，取一張單色影像要寫 `cube[k, :, :]`。

## 11. Pixel / Spaxel / Voxel（三個不要混淆）

| 名詞 | 維度 | 意義 | 在你 WFM 檔的數量 |
|------|------|------|------|
| **Pixel** | 2D | 偵測器上 / 一張影像裡的一格 | （泛稱）|
| **Spaxel**（spatial pixel）| 一個空間位置 | 一個 (x,y)，**內含一整條光譜** | 492 × 500 = 246,000 個 |
| **Voxel**（volume pixel）| cube 裡一格 | 一個 (x, y, 波長)，就是**一個數字**（某位置某波長的通量）| 492×500×3802 ≈ 9.35 億個 |

記憶法：Spaxel 是「空間上的一根針管」（一條光譜）；Voxel 是針管被切成的「一小段」（單一數值）。

## 12. HDU / Extension（DATA、STAT、DQ）

FITS 檔 = 一連串 **HDU (Header-Data Unit)**，每個 HDU = 一段 header（中繼資料）+ 一塊 data（陣列）。

你的檔案有 3 個 HDU：

| No. | 名稱 | 有無資料 | 內容 |
|-----|------|---------|------|
| 0 | `PRIMARY` | 無資料，只有 1565 行 header | 觀測的所有中繼資料（儀器、模式、座標、校正紀錄…）|
| 1 | `DATA` | (492,500,3802) float32 | **通量**（flux）立方體 = 你真正要分析的訊號 |
| 2 | `STAT` | (492,500,3802) float32 | **變異數**（variance）立方體 = 每個 voxel 的誤差平方 |

（有些 MUSE 產品還會有第 4 層 `DQ` = Data Quality，標記壞像素；你的檔沒有。）

🔑 **關鍵證據**：兩層的單位
- `DATA` BUNIT = `10**(-20)*erg/s/cm**2/Angstrom`
- `STAT` BUNIT = `(10**(-20)*erg/s/cm**2/Angstrom)**2`  ← **是 DATA 單位的「平方」**

單位被平方，就證明 STAT 存的是**變異數 (variance)**，不是誤差 (error)。
誤差 = `sqrt(STAT)`。這點直接接到 C 組（為什麼存變異數而不是誤差）。

## 13. WCS（World Coordinate System，世界座標系統）

WCS 把「像素索引」翻譯成「真實世界座標」（天球位置 + 波長）。靠 header 裡這組關鍵字：

- `CTYPEn`：這個軸是什麼（RA、DEC、波長）
- `CRPIXn`：參考像素的位置
- `CRVALn`：參考像素對應的真實值
- `CDn_n`：每走一個像素，真實值變化多少
- `CUNITn`：單位

你 WFM 檔的實際值：

| 軸 | CTYPE | 意義 | CRVAL（參考值）| CD（每像素）| 換算 |
|----|-------|------|------|------|------|
| 1 | `RA---TAN` | 赤經 RA | 9.22425 deg | -5.556e-5 deg | = **0.2″/spaxel**（×3600）|
| 2 | `DEC--TAN` | 赤緯 Dec | -33.55083 deg | +5.556e-5 deg | = **0.2″/spaxel** |
| 3 | `AWAV` | 空氣波長 | 4599.61 Å | 1.25 Å | = **1.25 Å/像素** |

- 空間每像素 0.2″ → 這就是 **WFM 的空間取樣**（之後 A 組會講）。
- `RA---TAN`：TAN 是切平面投影（把球面投到平面）；RA 的 CD 是負的，因為天文慣例「赤經往左增加」。
- 波長軸：第 k 個波長像素的波長 = `4599.61 + (k-1) × 1.25` Å。
  → 涵蓋 **4599.6 – 9350.9 Å**（注意起點 4600 比標準 480nm 更藍，暗示這是 Extended 模式，A 組再談）。
- `AWAV` = air wavelength（空氣中波長），相對於真空波長 VACUUM；做譜線比對時要留意用的是哪一種。

## 14. Flux units（通量單位）

`BUNIT = 10**(-20) * erg/s/cm**2/Angstrom`，逐項拆解（這是「**單位波長通量密度** F_λ」，且是每個 spaxel）：

| 部分 | 意義 |
|------|------|
| `erg` | 能量單位 |
| `/s` | 每秒 → erg/s = 功率（每秒多少能量）|
| `/cm**2` | 每平方公分 → 對應望遠鏡的集光面積 |
| `/Angstrom` | 每 1 Å 波長區間 → 因為是「光譜」，要講每單位波長多少能量 |
| `10**(-20)` | 純粹的縮放係數，避免數字太小（真實值乘上 1e-20）|

所以每個 voxel 的數值 = 「在那個空間位置、那個波長，每秒、每 cm²、每 Å，收到多少 erg 的能量」。
例如 cube 裡讀到 `150`，真實通量 = 150 × 10⁻²⁰ erg/s/cm²/Å。

---

## 本組小結

- MUSE 資料是 **(x, y, 波長)** 三維 **cube**；numpy 裡 shape 反序為 (波長, y, x)。
- **Spaxel** = 一條光譜的位置；**Voxel** = cube 裡一個數值。
- FITS 分 **PRIMARY（中繼資料）/ DATA（通量）/ STAT（變異數）**。
- STAT 單位是 DATA 的平方 → 它是**變異數**，error = sqrt(STAT)。
- **WCS** 把像素換成 RA/Dec 與波長；空間 0.2″/spaxel、波長 1.25 Å/像素。
- 通量單位是 F_λ：1e-20 erg/s/cm²/Å。

## 附錄：單位與 WCS 數值的深入解釋

### 通量單位 `1e-20 erg/s/cm²/Å`（逐塊讀）

| 符號 | 是什麼 | 白話 |
|---|---|---|
| `erg` | 能量 | 很小的能量；1 erg = 1e-7 焦耳 |
| `/s` | 每秒 | erg/s = 功率；1 瓦特 = 1e7 erg/s |
| `/cm²` | 每平方公分 | 對應望遠鏡鏡面集光面積 |
| `/Å` | 每 1 Å 波長 | 因為是光譜，講「每單位波長」收到多少 |
| `1e-20` | 縮放係數 | 天體很暗，先除掉 1e-20 再存，數字才好讀 |

這個量叫 **F_λ（單位波長通量密度）**。實例：cube 存 `50.763` → 真實值 `50.763 × 1e-20 = 5.08e-19 erg/s/cm²/Å`。

**STAT 為何是平方**：誤差與資料同單位；變異數 = 誤差²，單位也跟著平方（像 m → m²）。
所以 STAT 單位 `(erg/s/cm²/Å)²` 證明它是變異數，`誤差 = sqrt(STAT)`。

### 角度單位：`5.556e-5 deg` → `0.2″/spaxel`

天上的位置/大小都用**角度**量（天體太遠，只能講張開多大角）。角度階層（60 進位）：
```
1 度 = 60 角分 = 3600 角秒
```
`CD1_1 = 5.556e-5 度/像素` × 3600 = **0.2 角秒/像素**。
→ 每個 spaxel 在天上 = 0.2″ × 0.2″（滿月直徑約 1800″，可見其精細）。

### 波長單位：`1.25 Å/像素`

Å（埃）= 1e-10 公尺 = 0.1 nm；可見光約 4000–7000 Å。
`CD3_3 = 1.25` → 每個波長像素寬 1.25 Å（不需換算，CUNIT3 本來就是 Å）。

### WCS 三件套：CRVAL / CRPIX / CD

線性公式：
```
真實值 = CRVAL + (像素索引 − (CRPIX−1)) × CD
```
- `CRPIX` = 參考（錨點）像素（注意是 1-based，numpy 索引 0-based 要減 1）
- `CRVAL` = **錨點像素對應的真實世界值**
- `CD` = 每走一個像素，真實值變化多少

實例（波長軸）：CRPIX3=1, CRVAL3=4599.61, CD3_3=1.25
→ 像素0=4599.61 Å，像素1000=5849.61 Å。
空間軸 CRVAL1/2 = (9.224°, −33.55°) = 錨點 spaxel 在天上的 RA/Dec，把網格釘在 Haro 11 的位置。

### 這些數字哪裡來：校正 (calibration)

| 數字 | 校正種類 | 方法 |
|---|---|---|
| 通量單位 | 通量校正 | 觀測已知亮度標準星，反推「偵測器數字→物理通量」|
| 波長 (CRVAL3/CD3_3) | 波長校正 | 拍已知譜線的弧光燈，把像素對到已知波長 |
| RA/Dec | 天體測量校正 | 影像中的星比對星表，定出像素的天球座標 |
| STAT（變異數）| 誤差傳遞 | 從光子統計 + 偵測器雜訊算出每 voxel 變異數（見 C 組）|

header 是「校正後成品的說明書」，讀它就能把像素索引翻成物理意義。
