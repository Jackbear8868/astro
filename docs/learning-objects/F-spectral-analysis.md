# F. 光譜分析（specutils）

> 工具：**specutils**（astropy 生態的光譜分析套件）。
> 真實數字：從 `data/Haro11_nosky.fits` 最亮源 (x=331, y=239) 抽 5×5 加總光譜實測。
> 這組回到「光譜」本身——看一條光譜的形狀（連續譜 + 譜線），並量出紅移。

## 一條光譜由兩種東西組成
```
光譜 = 連續譜 (平滑底盤) + 譜線 (尖峰/凹谷)
                                ├ 發射線：凸出底盤 (氣體多發的光)
                                └ 吸收線：凹進底盤 (被吸收掉的光)
```

---

## 31. Emission / Absorption line（發射線 / 吸收線）

- **發射線 (emission line)**：在連續譜**之上凸起**的尖峰——氣體在某特定波長**多發**出光。
  - 成因：原子裡電子能階跳動，會放出**固定波長**的光子。每種元素能階不同 → 各有獨特波長 = **元素的指紋**。
  - 來源：被恆星照亮、游離的氣體（恆星形成區）。Haro 11 是劇烈恆星形成星系 → 發射線超強。
- **吸收線 (absorption line)**：在連續譜**之下凹陷**的凹谷——某波長的光被**吸收掉**。
  - 來源：恆星大氣、星系間/星際的冷氣體擋在光路上。
- **譜線符號**（會一直看到）：
  - 羅馬數字 = 游離程度：`I`=中性、`II`=游離一次、`III`=游離兩次（如 `[OIII]` = 氧被剝掉兩個電子）。
  - 中括號 `[ ]` = **禁制線 (forbidden line)**：只在極稀薄氣體（星雲）才發得出來，實驗室做不出。
- 真實證據（這條光譜實際偵測到的發射線）：
  Hβ、[OIII]4959/5007、[OI]6300、[NII]6548/6583、Hα、[SII]6716/6731——全部出現。
  - **Hα（H-alpha）**：氫最強的紅色發射線，恆星形成的招牌；這條光譜裡峰高/雜訊 ≈ **1228**。

---

## 32. Continuum（連續譜）

- **連續譜 (continuum)**：譜線底下那層**平滑、跨所有波長**的光，主要是**眾多恆星的光**疊加而成（stellar continuum）。
- 真實證據：這條光譜連續譜典型高度 ≈ **26403**；無線區的起伏(雜訊) std ≈ 2674。
- 譜線都是**相對於連續譜**來看的：發射線凸出它、吸收線凹進它。
  - 量一條線的真正強度，要用「線相對連續譜多出/少掉多少」（概念：**等值寬度 equivalent width**）。
- 實測解讀：發射線峰高上萬，遠高於連續譜起伏 → 確認 Haro 11 是**強發射線星系**。

---

## 33. Redshift / Rest-frame（紅移 / 靜止座標系）

- **紅移 (redshift, z)**：宇宙膨脹 → 遠方星系遠離我們 → 它的光波長被**拉長（變紅）**。這個拉長量就是 z。
  ```
  z = (觀測波長 − 靜止波長) / 靜止波長 = 觀測波長 / 靜止波長 − 1
  ```
- **靜止波長 (rest wavelength)**：譜線在**實驗室 / 在源自己座標系**的原始波長（如 Hα = 6562.8 Å）。
- **觀測波長 (observed wavelength)**：我們實際量到的（被拉長後、較長）。
- 真實測量：
  - 最強紅端發射線實測中心 = **6699.6 Å**，假設是 Hα(靜止 6562.8) →
    **z = 6699.6/6562.8 − 1 = 0.0208**（Haro 11 已知 z≈0.0206，吻合！）。
  - 退行速度 ≈ `cz` = **6253 km/s**（小 z 時 v≈cz）。
- **怎麼確定那條真的是 Hα？**（先有蛋還是先有雞）
  先猜最強線是 Hα → 得到試算 z → 用這個 z 預測**所有**其他線的觀測波長，看資料是否都有峰。
  實測 9 條線（Hβ、[OIII]、[NII]、[SII]…）全部對上 → z 確認。
- **rest-frame（靜止座標系）**：把整條光譜波長**除以 (1+z)**，把譜線「移回」實驗室波長，方便比對與分析（= 去紅移 / de-redshift）。
- 為何重要：有了 z 才能 ① 認出每條線、② 跟實驗室值比對、③ 換算星系的距離/速度。

---

## 本組小結

- 一條光譜 = **連續譜（平滑底，恆星光，~26000）** + **譜線（發射凸起 / 吸收凹陷）**。
- **發射線**＝氣體多發的光（凸），元素指紋；**吸收線**＝被吸收（凹）。符號：羅馬數字=游離度、`[ ]`=禁制線。
- **紅移** `z = 觀測/靜止 − 1`：實測 Hα 6699.6/6562.8 → **z=0.0208**（符合 Haro 11）；先猜 Hα 得 z、再用全部譜線驗證。
- **rest-frame**＝波長除以 (1+z) 移回實驗室座標，才能比對分析。
- 串起全局：E 組找到的源 → F 組抽它的光譜 → 量譜線與紅移 → 得到星系的物理（成分、運動、距離）。
