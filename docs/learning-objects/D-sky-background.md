# D. 天空與背景及其扣除（對應 ZAP）

> 用真實資料對照：`Haro11_wsky.fits`（含天空）與 `Haro11_nosky.fits`（已扣天空）
> —— **同一次觀測**（同視野 559×499、同波長、同曝光 700s），差別只在有沒有扣天空。
> 所以 `wsky − nosky` ＝ 被扣掉的天空本身。

---

## 前置詞彙（先定義，後面才用得到）

- **通量 (flux)**：望遠鏡每秒每單位面積每單位波長收到多少能量（B 組學過）。這裡數字單位都是 `1e-20 erg/s/cm²/Å`。
- **發射線 (emission line)**：光集中在**某一個特定波長**的尖峰（像光譜上一根針）。由特定原子/分子發出。
- **連續譜 (continuum)**：光**平滑地分布在所有波長**上的底盤（像一條緩慢起伏的基線）。
- **大氣 (atmosphere)**：地球的空氣層。地面觀測時，星光一定要先穿過它。

> 天文學講的「**天空 (sky)**」不是白天的藍天，而是指：**大氣自己發出、以及被散射進來的光**——它疊加在你每一個 spaxel 上，是你不想要、必須扣掉的東西。

從地面看一個星系，偵測器收到的其實是好幾層疊加：
```
偵測到的光 = 目標星系 + 天空(大氣自己的光) + 天文背景(太空其他雜光) + 偵測器背景(電子訊號)
```
D 組就是在搞懂這些雜層、並把它們扣掉。

## 23. Sky lines / Sky continuum（天空的兩種成分）

天空的光分兩種長相：

### 天空連續譜 (sky continuum) — 平滑底盤
- 來源：散射的月光、**黃道光 (zodiacal light，太陽光被太陽系內塵埃散射)**、散射的城市燈光、**氣輝連續譜**。
- **氣輝 (airglow)**：高層大氣（~90 km）的原子/分子白天被太陽曬「充能」、夜裡放出來的微光。
- 真實證據：空白天空在 5200 Å（沒有線的地方）連續譜底 ≈ **33**。

### 天光線 (sky lines / 天光發射線) — 尖峰
特定原子/分子在特定波長發出的亮尖峰：
- **[OI] 5577、6300 Å**：氧原子氣輝（[OI] = 中性氧的禁制線）。
- **Na D 5890 Å**：鈉原子氣輝（就是高層那層鈉——AO 雷射打的也是它）。
- **OH 線群**：**OH = 氫氧基（一種分子）**，在紅端/近紅外放出**一整片密集的線**（OH 森林）。
- 真實證據：
  - [OI]5577 ≈ 243、Na D ≈ 162、[OI]6300 ≈ 221、OH紅端 8400 ≈ 427。
  - 自動偵測最強天光線：5579 Å 及紅端 8346/8829/8889/8923/8960/9316/9326 Å（紅端全是 OH）。
  - **天光線比天空連續譜亮約 45 倍** → 天空的麻煩主要是這些線，尤其紅端 OH。

## 24. Sky subtraction（扣天空）

- **問題**：每個 spaxel 都是「目標 + 天空」。空白處只有天空；星系處是星系+天空。你要的是**純星系**。
- **做法**：估出天空光譜（用空白天空 spaxel，或另拍一張純天空），再從**每個** spaxel 減掉它。
- **檔名對照**：`wsky` = 扣之前（with sky）；`nosky` = 扣之後（no sky）。
- 真實證據（空白天空區中位通量）：

  | 波長 | wsky 含天空 | nosky 已扣 | 差＝天空 |
  |---|---|---|---|
  | 5200（連續譜）| 34.1 | 0.7 | 33.4 |
  | [OI]5577 | 243.8 | 0.9 | 242.9 |
  | Na D 5890 | 159.0 | −2.8 | 161.9 |
  | [OI]6300 | 221.0 | 0.5 | 220.5 |
  | OH 8400 | 426.1 | −1.3 | 427.4 |

  → 扣完後空白天空全部回到 ≈ 0（中位意義上扣得很乾淨）。
- **為什麼重要**：天光線可亮到 400+，常**遠亮於星系的暗弱外圍**；不扣掉就看不到星系的微弱結構。

### 殘餘 (residual) — 為什麼還需要 ZAP
扣天空**不可能完美**：天光線又亮又會隨位置/時間變動，扣的模型對不準就留下殘渣。
- 真實證據（`nosky` 空白區的**空間起伏 std**）：

  | 波長 | std（殘餘大小）|
  |---|---|
  | 5200（無線）| 3.06 ← 只是正常雜訊底 |
  | [OI]6300 | 8.86 ← 天光線殘餘，約 3 倍 |
  | OH 8400 | 8.28 ← OH 殘餘嚴重 |

  → 天光線位置的雜訊明顯較大，這些殘餘會假冒成特徵或淹沒弱訊號 → 需要進一步清除。

---

## 25. ZAP（用 PCA 清殘餘天光）

- **ZAP = Zurich Atmosphere Purge**，MUSE 專用的軟體（Soto et al. 2016），目的：清掉標準扣天空後**剩下的天光殘餘**。
- 先定義工具：**PCA（主成分分析，Principal Component Analysis）**＝一種「看過大量例子後，找出能解釋大部分變化的少數幾個共同樣式」的方法。
- ZAP 怎麼運作（白話）：
  1. 拿一堆**空白天空** spaxel——它們扣完天空後理論上應該全是 0，實際卻有殘餘。
  2. 這些殘餘**不是亂的**，反覆出現同樣的形狀（同一組天光線殘餘樣式）。
  3. PCA 把這些「共同樣式」抓出來（叫**主成分 / eigenspectra**）。
  4. 把這些樣式從**每一個** spaxel（含有星系的）減掉。
- 為什麼不會把星系也扣掉：星系的真實訊號**不屬於**那組「天空共同殘餘樣式」，所以 ZAP 移掉殘餘、卻大致保留星系。
- 為什麼用 PCA 而非再減一條天空譜：殘餘會隨位置/時間以複雜方式變動，PCA 能彈性抓住主要變動樣式。

## 26. Background（天文背景 vs 偵測器背景）

「背景」是個籠統詞，**一定要先問「哪來的背景」**。三種不同來源：

| 背景種類 | 是什麼 | 是光嗎 | 怎麼處理 |
|---|---|---|---|
| **天空 (sky)** | 大氣自己的氣輝、散射月光等（item 23）| 是（光子）| 扣天空 / ZAP |
| **天文背景** | 太空中**非目標**的真實光：黃道光、瀰漫銀河光、未解析的遠方星系 | 是（光子，來自大氣外）| 量空白天區、建模扣除 |
| **偵測器背景** | 偵測器**自己產生**的電子訊號（不是光）| 否（電子）| reduction 早期扣掉 |

偵測器背景再細分：
- **bias（偏壓）**：每次讀出都加上的固定底電位。
- **dark current（暗電流）**：就算沒光，熱也會激發電子累積（把偵測器冷卻可壓低）。
- （**read noise 讀出雜訊**屬 C 組——那是「雜訊」不是固定背景。）

🔑 重點：**天空與天文背景是「光」、偵測器背景是「電子」**，在不同步驟、用不同方法移除。

## 附錄：縮減流程順序、reconstruction vs subtraction、ZAP 定位

### 四種訊號是「按順序、分步驟」被拔掉的
```
① raw 讀出(也是fits)  含 目標+天空+天文背景+偵測器背景(電子)
② 偵測器層校正 → 扣【偵測器背景】 bias(固定底電位)/dark(暗電流)/flat(平場)
                  用校正幀處理，與天空無關，最早做；science cube 裡早已沒有它
③ 波長/通量校正、組 datacube
④ 扣天空【天空+天文背景】(一起) = 策略一：預測 sky 再 data − sky  ⇒ nosky.fits
⑤ (選用) ZAP = 策略二：預測 residual(PCA 近似) 再扣 → 清扣天空後殘餘的天光線
```
（④⑤ 兩種策略的細節見下方附錄「老師的框架」。）
→ 你手上的 `wsky/nosky` 是第④步前/後；偵測器背景在第②步就沒了。

### 天空 與 天文背景 是「一起」扣的
- 天空＝大氣自己的光（氣輝、散射月光）；天文背景＝大氣外非目標光（黃道光、瀰漫銀河光、未解析星系）。
- 兩者都「均勻鋪滿整個視野」→ 用「量空白 spaxel、減到每格」一招就**同時**扣掉，分不開也不必分。
- 真實證據：被扣掉的天空在「空白處 vs 星系核」幾乎相同（[OI]6300：213.6 vs 218.2，差 2%）→ 證明它是均勻疊加層。

### ⚠️ 重要：老師的框架——「預測 sky」vs「預測 residual」是兩種策略（非兩階段）
> 更正：先前把 reconstruction/subtraction 寫成「一套方法的兩步」(pipeline 內部用語)。
> **老師的用法是把兩者當成互相競爭的兩種策略**，以老師框架為準。

資料模型：`data = object + sky`（+ 雜訊），目標是還原 object。兩條路：

| | 策略一：預測 sky（老師要的）| 策略二：預測 residual（ZAP/PCA）|
|---|---|---|
| 對什麼建模 | **天空本身**（物理對象：連續譜+天光線+LSF）| 粗扣後剩下的**殘餘**（副產品）|
| 做法 | `object = data − sky_model` | 先粗扣一次 → PCA 近似殘餘 → 再減 |
| 誤差 | 較小、可控（建模對象有規律可懂）| 較大、兩層誤差疊加、且有殘餘抓不到 |
| 需要 | 好的 LSF + 天光線清單 + 空白取樣 | 夠多空白 spaxel 學共同樣式 |
| 結論 | ✅ 老師要走這條 | ❌ 不希望依賴這條 |

- 我的筆記關鍵詞正確：**ZAP = reproduce residual approximate**（近似重建殘餘）= 策略二。
- 為何策略二誤差大（老師的理由）：① residual 半結構半隨機（來自 LSF/波長/尖線次像素誤差），不是物理實體；
  ② PCA 只抓共同、線性的少數樣式 → 罕見/局部/非線性殘餘抓不到（＝有些 residual 預測不好）；③ 誤差疊加、且可能誤扣星系。
- 為何策略一較好：建模的是「物理上可懂的天空」（線清單、LSF 可量），誤差較可控。
- 旁證：實測同一格 [OI]6300 在不同 spaxel 散布達 **48.9%** → 天空模型必須隨位置調 LSF 才減得準（屬策略一要把 sky 預測好）。

#### 🔑 關鍵實證：PCA 量化「誰好預測」（3000 空白spaxel, 5100–9000Å）
> PCA = 把資料拆成「幾個共同樣式 + 權重」；少數樣式就重建出大部分 = 好預測。

| | 天空本身 | 扣後殘餘 |
|---|---|---|
| 第1樣式解釋 | **72.3%** | **8.8%** |
| 前5樣式解釋 | 88.6% | 16.3% |
| 前50樣式解釋 | 96.7% | 33.7% |
| 解釋90%需幾個樣式 | **7 個** | **1083 個** |

- **天空 ≈ 單一形狀**（全場同一條氣輝譜疊著）→ 超好建模 → 策略一誤差小。
- **殘餘 = 少量結構(8.8%) + 大量隨機雜訊** → 雜訊**本質無法預測**（這就是老師說「有些 residual 預測不好」）→ 策略二誤差大。
- ZAP 能扣掉那「8.8% 結構部分」（天光線殘渣），故適合當**最後精修**；但碰不到雜訊，**不該當主力**。

#### 策略一的三個施作重點（老師方向）
1. 空白天空取樣（選對/選夠 sky spaxel，或用 offset sky）。
2. 天光線擬合（用線清單把每條線強度擬準）。
3. LSF 建模（讓 sky model 隨**每個位置**的解析度調整）→ 減得準的關鍵。
目標：讓 `data − sky` 一刀就乾淨，不依賴 ZAP 追殘渣。

### ZAP 專攻什麼
- 只清「扣天空後剩下的天光殘餘」，主要是**天光線殘渣**（實測 6300/8400Å 處 std 由 3→8~9）。
- 不碰偵測器背景(已沒)、不碰天文背景主體(已隨天空減掉)、盡量不碰星系(不屬 PCA 共同樣式)。
- 定位＝「扣天空的精修第二刀」。

## 本組小結

- 地面觀測收到的 = 目標 + **天空** + 天文背景 + 偵測器背景；D 組在扣掉雜層。
- **天空 = 天空連續譜（平滑底，~33）+ 天光線（尖峰，亮約 45 倍）**；紅端是 OH 森林。
- **扣天空**：估天空再從每格減掉。`wsky`(扣前) → `nosky`(扣後)，空白區由 ~400 降到 ~0。
- 扣不完美 → **殘餘**（天光線處 std 3→9）→ 用 **ZAP（PCA）** 學出殘餘共同樣式再清掉，保留星系。
- **「背景」分三種**：天空(大氣光)、天文背景(太空光)、偵測器背景(電子)——來源不同、處理不同。
