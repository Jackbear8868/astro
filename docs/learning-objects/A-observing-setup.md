# A. 望遠鏡 / 儀器的觀測設定（檔名與 header 裡藏的資訊）

> 望遠鏡：ESO VLT UT4 (Yepun) ＋ MUSE 光譜儀。
> 最關鍵的一個 header 關鍵字：`HIERARCH ESO INS MODE`，格式 = **視野模式-AO-波長範圍**。

## 四個檔的觀測設定對照（全部讀自真實 header）

| 檔 | INS MODE | 視野 | AO | E/N | 空間取樣 | 波長範圍 (Å) | 曝光 | 大氣 seeing | 鈉缺口 |
|---|---|---|---|---|---|---|---|---|---|
| `Haro11_WFM_MUSE_archive.fits` | `WFM-NOAO-E` | 廣 | 無 | Extended | 0.200″ | 4599.6–9350.9 | 22400s(疊32) | ~1.1″ | 無 |
| `Haro11_NFM_ESO_nosky.fits` | `NFM-AO-N` | 窄 | **有** | Nominal | 0.0252″ | 4750.2–9347.7 | 1148s | 0.43–0.52″ | **有(5783–6005=0)** |
| `Haro11_wsky.fits` | `WFM-NOAO-E` | 廣 | 無 | (裁切) | 0.200″ | 4750.2–9347.7 | 700s | ~0.95″ | 無 |
| `Haro11_nosky.fits` | `WFM-NOAO-E` | 廣 | 無 | (裁切) | 0.200″ | 4750.2–9347.7 | 700s | ~0.95″ | 無 |

> `INS MODE` 一行就把 1、2、3 三個概念全講了：`WFM-NOAO-E` = 廣視野 + 無調適光學 + Extended 波長。

---

## 1. WFM / NFM — 視野模式（Field Mode）

| | WFM（Wide Field Mode）| NFM（Narrow Field Mode）|
|---|---|---|
| 視野 (FoV) | 1′×1′（≈60″）| 7.5″×7.5″ |
| 空間取樣 | 0.2″/spaxel | 0.025″/spaxel（8 倍細）|
| 標準格數 | 300×300 | 300×300 |
| 適合 | 整個星系、大尺度結構 | 核心、極高解析細節 |

- 真實證據：WFM 檔 492×500 spaxel × 0.2″ ≈ 98″×100″（≈1.6′；比單次 1′ 大，因為疊了 32 次並做了 dither，footprint 變大）。
- 真實證據：NFM 檔 343×340 × 0.0252″ ≈ 8.6″×8.6″（≈7.5′′ 視野 + 一點邊）。
- 取捨：WFM「看得廣但粗」；NFM「看得細但小」。同一個天體（Haro 11）兩種模式都拍 = 一個看全貌、一個看核心。

## 2. AO / NOAO — 調適光學（Adaptive Optics）

- **AO（調適光學）**：用**雷射導星**（射一道鈉雷射到天上約 90 km 高的鈉原子層，製造一顆人造星）量測當下大氣擾動，再用**變形鏡**每秒上千次即時修正 → 把被大氣抹開的影像「拉回清晰」。
- **NOAO**：不開 AO，影像清晰度只能聽天由命（受當晚 seeing 限制）。
- NFM **必須**搭配 AO（沒有 AO 就沒意義，因為 0.025″ 的細節會被大氣糊掉）；WFM 可開可不開。
- 真實證據：NFM-AO 檔大氣 seeing 才 0.43–0.52″，AO 還能再把點源壓更銳；WFM-NOAO 檔影像清晰度 ≈ 當晚 seeing ~1.1″。

## 3. E / N（Extended / Nominal）— 波長涵蓋範圍

- **Nominal (N)**：≈ 4800–9300 Å。藍端有擋板擋掉 <4800，避免紅端的二階光（2nd-order）污染。
- **Extended (E)**：≈ 4600–9300 Å。拿掉藍端擋板，**多看到約 4600–4800 Å 這段更藍的光**（代價：紅端可能有少量二階污染）。
- 真實證據（最漂亮的對照）：
  - WFM-**E** 檔波長從 **4599.6** Å 起跳（藍）。
  - NFM-**N** 檔波長從 **4750.2** Å 起跳（沒那麼藍）。
  - → 檔名/header 的 E、N 直接反映在資料的藍端起點。

## 4. Spatial sampling / spaxel scale — 每個空間格子代表天上多大

- 定義：一個 spaxel 對應天上多少角秒（= plate scale）。讀自 WCS 的 `CD1_1`。
- WFM：`|CD1_1|=5.556e-5 deg ×3600 = 0.200″/spaxel`。
- NFM：`|CD1_1|=6.997e-6 deg ×3600 = 0.0252″/spaxel`。
- ⚠️ 取樣 ≠ 解析度：spaxel 多細是「取樣」；能不能看清細節還要看 seeing/PSF（item 7）。WFM 取樣 0.2″ 但 seeing ~1″ → 真正能分辨的尺度是 ~1″，不是 0.2″。

## 5. Spectral resolution (R) — 能把多接近的兩條譜線分開

- 定義：`R = λ / Δλ_FWHM`，R 越大、能分開越靠近的兩條線。
- MUSE 的 R 隨波長變大：藍端 ~1770（4650Å）→ 中段 ~2400（6000Å）→ 紅端 ~3590（9300Å）。
- 換成速度解析度 `c/R`：約 **85–170 km/s**（紅端較好）。→ 比這更窄的速度差就分不開。
- 註：R 不在這份 header 裡，是儀器固有規格；實務上用「弧光燈譜線寬度」量得 LSF（line spread function）。

## 6. Spectral sampling — 每個波長像素間隔多少 Å

- 真實證據：`CD3_3 = 1.25 Å/像素`（四個檔一致）。
- ⚠️ 取樣 ≠ 解析度：解析元素（LSF FWHM）≈ 2.5 Å，被 1.25 Å 的像素切成約 **2 個像素**（Nyquist 取樣，剛好夠）。
- 所以「波長取樣 1.25 Å」比「解析度 ~2.5 Å」細——取樣是為了不浪費解析度。

## 7. Seeing / PSF / FWHM — 點光源被抹開的程度

- **Seeing**：大氣擾動把點源（理論上一個點）抹成一個小團，這團的寬度（FWHM）就是 seeing，數值越小越清晰。
- **PSF（point spread function）**：點源在影像上實際的形狀；它的 FWHM 就是清晰度指標。
- 真實證據（header 大氣 FWHM）：WFM ~1.1″、wsky/nosky ~0.95″、NFM 0.43–0.52″（再加 AO 修正會更銳）。
- 關聯：seeing 決定你「實際」能分辨多細，常比 spaxel 取樣粗。AO（item 2）就是用來打敗 seeing 的。

## 8. Sodium notch（鈉雷射缺口）— AO 模式下 ~5800–6000 Å 被擋掉

- 開 AO 時，鈉雷射（589 nm = 5890 Å）的光會反污染資料，所以**用陷波濾鏡把那段波長擋掉**，該區資料無效。
- 真實證據：
  - NFM-**AO** 檔：約 **5783–6005 Å** 的 DATA 和 STAT **整段 = 0**（零值比例 100%）→ 就是缺口。
  - WFM-**NOAO** 檔：同段波長**完全正常**、無缺口；反而在 5890/5896 Å 看到變異數飆高（23.8、21.2）= 大氣自己的**鈉 D 天光線**（屬 D 組）。
- 口訣：**有 AO 才有鈉缺口**；看到 5800–6000 Å 一片 0，就知道這是 AO 資料。

## 9. Exposure time / Airmass — 曝光時間、天體離天頂多遠

- **Exposure time（曝光）**：收光越久訊號越多，SNR ∝ √時間（接 C 組）。
  - 真實證據：WFM `EXPTIME≈8656s`、`TEXPTIME=22400s`、`NCOMBINE=32`（疊 32 次 → 又深又能去宇宙射線）；NFM 1148s；wsky/nosky 各 700s。
- **Airmass（大氣質量）**：`≈ 1/cos(天頂角)`。=1 表示正對天頂（穿過最少大氣）；越大穿越越多大氣 → 消光更重、seeing 更差。
  - 真實證據：四個檔 airmass 都 1.04–1.10（幾乎在頭頂正上方，觀測條件好）。

---

## 本組小結

- **`INS MODE` 一行定生死**：`視野(WFM/NFM)-AO(AO/NOAO)-波長(E/N)`，把 1、2、3 全寫好了。
- **WFM**：廣(1′)、粗(0.2″)、看全貌；**NFM**：窄(7.5″)、細(0.025″)、需 AO、看核心。
- **AO** 用雷射導星+變形鏡打敗 seeing；代價是 **5800–6000 Å 鈉缺口**（資料=0）。
- **E vs N** 差在藍端起點（E≈4600 比 N≈4800 更藍）——真實檔 4599.6 vs 4750.2 對得上。
- **取樣 ≠ 解析度**：空間 0.2″/spaxel vs seeing~1″；波長 1.25 Å/像素 vs LSF~2.5 Å。
- **曝光久→SNR 高（√t）**；**airmass 越小→大氣越少→越好**（本資料都接近天頂）。

## 附錄：AO / seeing / 解析度 / 取樣 / Nyquist 深入版（含實測）

### AO（調適光學）到底在做什麼

- **問題**：地球大氣有一塊塊溫度/密度不同的湍流氣團，折射率不同 → 把進來的星光隨機折彎，且每秒變上百次。一顆點星因此被抹成 ~1″ 的團、還會閃（星星「眨眼」的原因）。
- **AO 三步驟即時修正**：
  1. **波前感測器**量出當下波前被扭曲成什麼樣（需一顆參考星）。
  2. **雷射導星 (LGS)**：射強力鈉雷射激發 ~90 km 高鈉層發光，**造一顆人造星**，這樣望遠鏡指哪都有參考星。
  3. **變形鏡**：薄鏡背後數百個致動器，每秒上千次把鏡面凹凸成「反扭曲」去抵銷 → 波前被拉平 → 星光重新聚成銳利的點。
- **影響/效果**：PSF 變銳（FWHM 變小）→ 看到更細結構；光被收進更小區域 → 點源峰值 SNR 更高、更好分離重疊源。
- **代價**：① 鈉缺口（5800–6000 Å 被擋，item 8）；② AO 效果隨條件變動、紅端較佳、PSF 常是「銳核 + 寬暈」。

### seeing 是什麼、為什麼 WFM/NFM 不一樣

- **seeing**：純由大氣湍流造成的點源 PSF 寬度（FWHM，單位角秒）。Paranal 中位 ~0.8″，逐夜逐時都在變。
- **無 AO 時，影像解析度 = seeing**，跟望遠鏡多大、像素多細無關 —— 你不可能比 seeing 更清楚。
- 為什麼兩模式交付清晰度差很多，**不是大氣本質不同**，而是：
  - WFM 這裡是 **NOAO**（沒修正）→ 被 seeing 鎖死。
  - NFM 用 **AO**（修掉大氣）→ 遠優於 seeing。
- **實測對照（白光影像最亮團塊視寬）**：
  ```
  WFM-NOAO: FWHM = 0.92″   ≈ 當晚 seeing ~1.1″  → 證明它被 seeing 限制
  NFM-AO  : FWHM = 0.16″   遠小於 seeing        → 證明 AO 真的把細節拉出來
  ```
- 🔑 **空間取樣也是配合 PSF 選的（Nyquist 的空間版）**：WFM PSF~1″ → 0.2″/spaxel（每個 PSF ~5 格）；
  NFM AO PSF~0.05–0.1″ → 0.025″/spaxel（每個 PSF ~3 格）。NFM 取樣細 8 倍，正因為 AO 把 PSF 變銳了 8 倍。

### 解析度 vs 取樣 vs Nyquist（光譜版，含實測）

- **解析度 R**：`R = λ / FWHM_LSF`。LSF（line spread function）= 一條「無限窄」的線經過儀器後被抹開的寬度。
- **取樣 (sampling)**：相鄰像素的波長間隔 = `CD3_3 = 1.25 Å/像素`。這是「數位化多細」，不是「實際多銳」。
  - 比喻：解析度 = 照片多模糊；取樣 = 存成幾百萬畫素。模糊照片存超高畫素還是模糊。
- **Nyquist 取樣定理**：要不漏失資訊，每個 FWHM 至少要取 ~2 個樣本（取樣間隔 ≤ FWHM/2）。
  - 取太疏（<2/FWHM）→ 欠取樣 (undersampling)，會漏細節甚至產生假訊號 (aliasing)。
  - 取太密（>>2/FWHM）→ 過取樣，沒多資訊只是檔案變大、相鄰像素雜訊相關（接 C 組）。
- **實測（`wsky` 檔的大氣輝線，本身近乎無限窄 → 量到的就是 LSF）**：
  ```
  [OI] 5577 Å : FWHM = 2.88 Å → 2.3 像素/FWHM → R = 1939 → c/R = 155 km/s
  [OI] 6300 Å : FWHM = 2.90 Å → 2.3 像素/FWHM → R = 2171 → c/R = 138 km/s
  ```
- 🔑 兩個關鍵觀察：
  1. **FWHM ≈ 固定 2.9 Å**（不隨波長變），但 **R = λ/FWHM 隨波長變大**（λ 變大、分母不變）→ 這就是 item 5 說的 R 藍小紅大。
  2. **每 FWHM 被切成 2.3 像素** → 剛好略高於 Nyquist 下限 2 → MUSE 是「臨界取樣」，不浪費也不漏失。
