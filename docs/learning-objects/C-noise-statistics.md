# C. 像素層級的測量、雜訊與統計

> 用真實資料對照（`Haro11_WFM_MUSE_archive.fits`，波長切片 ≈7100 Å）：
> - 最暗 10% spaxel：平均通量 −4.0，平均變異數 **4.47**
> - 最亮 10% spaxel：平均通量 24.9，平均變異數 **7.91**
> - 亮處變異數 > 暗處 → Poisson；暗處變異數仍 ≠ 0 → 讀出雜訊底線
> - SNR 中位數 0.33（大多是空白天空），最亮源達 225

核心問題（承接 B 組）：**為什麼 STAT 存「變異數」而不是「誤差」？**
答案在 19：**變異數可以相加，誤差不行。**

---

## 15. Pixel 的物理意義：測量 = 真值 + 雜訊

一個 voxel 的數值**不是真理**，而是一次「測量」：
```
測到的值 = 真實訊號 + 隨機雜訊
```
每次測量都有不確定度。STAT 就是在量化「這個不確定度有多大」。

## 16. Counts / ADU / electrons / Gain（雜訊的源頭在這層）

光子打到偵測器的過程：
```
光子 → 打出電子(光電效應) → 偵測器數電子 → 數位化成 ADU(counts) → 校正成物理通量
```
- **ADU / counts**：偵測器輸出的原始數字（Analog-to-Digital Unit）
- **electron (e⁻)**：實際被光子打出的電子數
- **Gain（增益）**：兩者的換算，單位 e⁻/ADU，`電子數 = ADU × gain`

🔑 為什麼重要：**Poisson 統計作用在「電子數（光子數）」上**，不是直接在通量上。
你的 cube 已是通量單位，但雜訊是先在電子層級算好，再一路換算（傳遞）到通量單位存進 STAT。

## 17. Signal vs Noise

- **Signal（訊號）**：你要的真實天體光。
- **Noise（雜訊）**：疊在上面的隨機起伏，來自測量過程，每次都不同。
- 量化雜訊大小的方式就是它的「散布程度」→ 標準差。

## 18. Error / Uncertainty（誤差 = 標準差 σ）

- **誤差不是「算錯」**，是測量本身的不確定度。
- 寫成 `通量 = 50.8 ± 1.6`：若重複觀測，結果會以真值為中心、散布幅度約 1.6。
- 誤差與資料**同單位**（通量誤差單位也是 erg/s/cm²/Å）。

## 19. Variance（變異數 = σ²）★ 本組關鍵

- 定義：`變異數 = 誤差²`，單位是資料單位的平方（所以 STAT BUNIT 是平方）。
- **為什麼存它而不是誤差**：對「獨立」雜訊，**變異數可以直接相加**：
```
Var(A + B) = Var(A) + Var(B)            ✓ 相加
誤差(A+B) = sqrt(Var(A)+Var(B)) ≠ 誤差(A)+誤差(B)   ✗ 不能相加
```
- 你做的每件事都在合併測量 → 變異數讓誤差傳遞變成單純相加：
  - 把多個 spaxel 加起來（孔徑測光）
  - 沿波長合併（binning）
  - 扣天空（相減，變異數仍是相加！）
- 用法：要誤差就 `誤差 = sqrt(STAT)`。

## 20. Poisson noise（光子散粒雜訊）— 隨訊號變大

- 光以「一顆顆光子」隨機到達，像數雨滴落進桶子，數目會隨機起伏。
- Poisson 統計：若期望數到 N 顆，則 **變異數 = N，誤差 = √N**。
- 特徵：**變異數 = 訊號量** → 越亮、雜訊絕對值越大，但相對精度變好。
- 真實證據：亮 spaxel 變異數 7.91 > 暗 spaxel 4.47，多出來的就是 Poisson。

## 21. Gaussian noise（讀出雜訊）— 固定底線，與訊號無關

- 偵測器把電子讀出來時，電路會加上**固定大小**的隨機起伏 = 讀出雜訊 (read noise)。
- 分布呈鐘形（高斯），大小與訊號多寡無關 → 形成一條「雜訊底線」。
- 真實證據：通量≈0 的暗 spaxel，變異數仍有 ≈4.47，不會變成 0。
- 註：Poisson 在 N 很大時也趨近高斯形狀，所以總雜訊常被當高斯處理。

### 總雜訊（兩者相加，因為變異數可加）
```
總變異數 = Poisson 變異數(=訊號電子數) + 讀出雜訊² + 背景貢獻 + …
```
STAT 就是把以上全部換算到通量單位後的結果。

## 22. SNR（訊雜比）

```
SNR = 訊號 / 雜訊 = 通量 / 誤差 = DATA / sqrt(STAT)
```
- 判讀可信度：SNR ≳ 5 通常算可信偵測；SNR < 3 幾乎與雜訊難分。
- 真實證據：空白天空 SNR 中位數 0.33；亮源處達 225。
- 如何提高 SNR：
  - 曝光更久（Poisson：SNR ∝ √時間）
  - 合併 spaxel / 合併波長（用變異數相加來降低相對雜訊）

---

## 本組小結

- 每個 voxel 是「真值 + 隨機雜訊」；STAT 量化雜訊。
- 雜訊兩大來源：**Poisson**（隨訊號上升，變異數=訊號）+ **讀出/高斯**（固定底線）。
- **變異數可加、誤差不可加** → 這就是 MUSE 存 STAT（變異數）的原因。
- **SNR = DATA / sqrt(STAT)**，是判斷資料可不可信的核心指標。

## 附錄：一個完整走過一遍的真實 voxel（7099.6 Å 切片）

在最亮的源中心挑一個 voxel（numpy 索引 y=237, x=247）：

```
DATA  (通量)   = 3067.20        ← 收到的訊號
STAT  (變異數) =  185.33        ← 這個測量的雜訊平方
誤差 = sqrt(STAT) = 13.61       ← 還原成「同單位」的不確定度
寫成               : 通量 = 3067 ± 14
SNR  = DATA/誤差   = 225        ← 高到不可能是雜訊湊出來的 → 確定是真源
```

把這個亮 voxel（變異數 185）對照暗天空 voxel（變異數 ≈4.47）：差距幾乎全部來自 Poisson
（訊號越強，光子數越多，變異數跟著漲）。這就是「變異數 = 訊號量」最直接的證據。

整張 7099.6 Å 影像裡，SNR > 5（可信偵測門檻）的 spaxel 只佔 **4.4%** —— 因為視野絕大部分是
空白天空，真正有源的地方很少。這也解釋了為什麼 SNR 中位數只有 0.33。

## 附錄：有了 SNR 之後會發生什麼？DATA ↔ STAT 還有哪些關聯？

### (一) SNR 的下游用途：算出來之後拿來幹嘛

| 用途 | 怎麼用 SNR |
|------|-----------|
| **源偵測（E 組）** | 偵測門檻直接用 SNR 定義（如 > 5 才算源），低於的當雜訊丟掉 |
| **測量精度** | **相對誤差 ≈ 1 / SNR**。SNR 5→誤差20%；100→1%；225→0.4% |
| **非偵測 → 上限值** | 低於門檻不報「測到多少」，改報「**upper limit**（≤ 3σ）」 |
| **要不要 binning** | per-voxel SNR 太低 → 合併 spaxel/波長把 SNR 拉到目標值 |
| **譜線偵測（F 組）** | 一條發射線「算不算測到」也是看它的 SNR |
| **遮罩 / 加權** | 低 SNR voxel 遮掉或降權；合併時用 1/STAT 當權重 |

**沒有單一硬門檻**，門檻取決於你要做什麼科學：

| 科學目標 | 需要的 SNR（大略）|
|---|---|
| 只想知道「有沒有源」| 3–5 |
| 測通量到 ~10% | ~10 |
| 量恆星運動學（速度、速度彌散）| 每個 bin ~30–50 |
| 詳細譜形 / 恆星族群擬合 | 100+ |

- **低於門檻**：與雜訊分不開 → 視為非偵測、改報上限、排除出星表、擬合時遮掉。
- **高於門檻**：算真偵測 → 可給有意義誤差棒；SNR 越高能量越細的東西（譜線比、速度、微弱特徵）。

### (二) SNR 不是物件的固定屬性

同一個源，**per-voxel SNR 可能很低，但整合後（integrated）SNR 很高**。SNR 取決於你怎麼合併：
- 空間上變化：源中心高、天空低。
- 光譜上變化：發射線位置高、連續譜低、天光線殘餘區更糟。

### (三) DATA 與 STAT 的其他關聯（不只 SNR）

1. **STAT ≈ a×DATA + b**（實測擬合 `變異數 ≈ 0.050×通量 + 3.26`）：
   斜率>0 = Poisson，截距>0 = 讀出雜訊底線。這就是第 20、21 點的合體。
2. **合併運算時 STAT 必須跟著傳遞**（誤差傳遞）：
   ```
   相加 N 格:  DATA→ΣDATA,      STAT→ΣSTAT
   取平均:     DATA→ΣDATA/N,    STAT→ΣSTAT/N²
   乘常數 c:   DATA→c·DATA,      STAT→c²·STAT
   扣天空:     DATA→DATA−sky,    STAT→STAT+STAT_sky   (相減但變異數相加!)
   最佳合併:   用 權重 = 1/STAT 做加權平均 (inverse-variance weighting)
   ```
3. **DATA、STAT 共用同一組 WCS、同 shape、NaN 位置一致**。
4. **可用空白天空『實測散布』反查 STAT 可不可信**：
   理論上 空白區 DATA 的標準差 ≈ sqrt(STAT)。

### (四) ⚠️ MUSE 陷阱：STAT 會「低估」真實雜訊（相關雜訊 correlated noise）

實測（空白角落區）：
```
實測雜訊 = DATA 標準差      = 3.64
預測雜訊 = sqrt(STAT) 中位數 = 2.01
比值 ≈ 1.8  → 實際雜訊比 STAT 說的「大」約 1.5–2 倍
```
原因：資料縮減（reduction）過程做了**重新取樣／內插**，使**相鄰 voxel 的雜訊彼此相關**。
STAT 只記「單像素的形式變異數」，沒含這份相鄰相關 → 系統性低估。

後果：
- 合併 spaxel 時雜訊**降得比 √N 慢一點**（鄰格不完全獨立）。實測 √N 定律仍大致成立：
  合併 1→4→16→64 格，殘餘雜訊 3.69→2.01→0.95→0.42（≈ 1/√N）。
- 嚴謹估誤差（尤其孔徑測光、binning）時，要對 STAT 乘一個經驗修正因子，否則誤差會被低估、SNR 被高估。

### (五) inverse-variance weighting（反變異數加權）

要把「對同一個量的多次測量」合併成一個值時：
- **簡單平均**：每個測量一視同仁 → 很吵的那個會把結果拖歪。
- **反變異數加權**：權重 = `1/變異數 = 1/STAT`，**雜訊小的測量講話比較大聲**。
```
合併值 = Σ(xᵢ/σᵢ²) / Σ(1/σᵢ²)        合併後變異數 = 1 / Σ(1/σᵢ²)
```
- 它是「最小變異數」最佳估計（達到理論下限）。實測：合併 225 個變異數差很大（3→185）的測量，
  簡單平均誤差 0.313、IVW 誤差 0.221（= 理論下限），**IVW 小 29%**。
- 用途：把 spaxel 併成一條光譜、疊多次曝光、binning。→ 這也是 STAT 除了算 SNR 外的第二大用途：**當權重**。

### (六) correlated noise（相關雜訊）定義

- 理想：每個像素的雜訊**彼此獨立**（像各自擲硬幣）→ 相鄰像素相關係數 ≈ 0。
- MUSE 現實：reduction 把資料**內插／重取樣**到規則網格，每個輸出像素是好幾個偵測器像素的混合
  → 相鄰像素**共用了部分雜訊** → 相關。
- 實測：空白天空相鄰像素相關係數 右鄰 +0.14、下鄰 +0.18（>0 即相關）。
- 後果：見 (四)——STAT 低估總和的真實雜訊、√N 降噪變慢。

### (七) 那 STAT 要一直跟著運算、同時維護嗎？

**概念上：是。** DATA 與 STAT 永遠成對，對 DATA 的每個運算都有對應的 STAT 運算（誤差傳遞）。
實測孔徑加總 225 格：ΣDATA=115466、ΣSTAT=5034 → 誤差 71 → 整合 SNR 從單格 225 跳到 **1627**。

**實務上：不用手動維護**，用會「成對搬運 data+var」的工具，傳遞自動完成：
| 工具 | 說明 |
|---|---|
| **MPDAF**（MUSE 專用，建議）| `Cube/Image/Spectrum` 物件同時帶 `.data` 與 `.var`，做算術會自動傳遞變異數（本機未安裝）|
| astropy `NDData`/`CCDData` + uncertainty | 通用，帶不確定度一起傳遞 |
| specutils `Spectrum1D` + uncertainty | 光譜分析用（F 組會用到）|

若像我們現在直接用裸 numpy，就**必須自己套 (三) 的傳遞規則**手動算 STAT。
