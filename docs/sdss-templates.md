## 3. 檔案結構

每個 `.fit` 是單一 image HDU,shape `(4, N)`,`float32`。四個 row 依 SDSS spSpec 慣例為:

| row | 內容 |
|---|---|
| **0** | **光譜** ← 建模使用這一列 |
| 1 | 扣掉連續譜的光譜 |
| 2 | noise |
| 3 | mask |

### 波長軸

`DC-FLAG = 1`,波長為**等 log₁₀λ 取樣**:

    λ(i) = 10^(COEFF0 + COEFF1 · i),  i = 0 … NAXIS1−1

全部 33 條的 `COEFF1 = 10⁻⁴`,換算為固定速度間隔:

    Δv = COEFF1 · ln(10) · c = 69.0 km/s / pixel

MUSE cube 為**等波長取樣**(`CD3_3 = 1.25 Å`)。兩者格點規則不同,
模板必須先**重採樣到 MUSE 的波長格點**才能與資料相減。

## 4. 波長覆蓋 vs MUSE(Haro 11,z = 0.0206)

`Haro11_NEpointing_wsky.fits` 的波長軸為 **4599.66 – 9349.66 Å**
(`NAXIS3` = 3801,`CD3_3` = 1.25 Å;MUSE extended mode,藍端較標稱的 4750 Å 多出 150 Å)。
換算成靜止座標系:

    需要的靜止波長 = 4599.66 / 1.0206  到  9349.66 / 1.0206  =  4506.8 – 9160.9 Å

| 模板 | 靜止覆蓋 | 是否涵蓋 4506.8–9160.9 Å |
|---|---|---|
| 0–22(恆星) | ~3810 – 9200 Å | 是 |
| **23–27(星系)** | **3500 – 9197.5 Å** | **是**(紅端餘裕僅 36.6 Å) |
| 28(LRG) | 3000 – 6800 Å | 否,缺紅端 |
| 29(QSO) | 700 – 8500 Å | 否,缺紅端 |
| 30–31(BAL QSO) | ~1000 – 3500 Å | 否,純紫外 |
| 32(高光度 QSO) | 1350 – 6572 Å | 否,缺紅端 |

**可用於擬合 Haro 11 的星系模板為 23、24、25、26、27 五條。**

對視場中的**前景恆星**(z ≈ 0)則需涵蓋觀測的 4599.66–9349.66 Å;恆星模板僅到 ~9200 Å,
紅端缺約 150 Å。兩種紅移情況的可用窗口不同,需分別計算。

## 4b. 空氣波長 vs 真空波長(必要的轉換)

MUSE cube 的 `CTYPE3 = AWAV`,波長軸是**空氣波長**;SDSS 光譜為**真空波長**。
兩者不轉換直接比對,會造成 **約 83 km/s 的系統性紅移偏差**(空氣折射率
n ≈ 1.000277,對應 Δz ≈ 2.77 × 10⁻⁴)。

轉換方向取**空氣 → 真空,作用在 MUSE 的波長軸上**,而非反向:
折射率是**觀測波長**的函數,若改為把模板由真空轉空氣,必須在紅移之後進行,
於是每一個 z 都要重算一次;轉換 MUSE 軸則與 z 無關,整個程式只需計算一次。

    lam_vac = lam_air · n(lam_air)

    s  = 10⁴ / lam_air
    n  = 1 + 8.336624212083e-5
           + 2.408926869968e-2 / (130.1065924522 − s²)
           + 1.599740894897e-4 / (38.92568793293 − s²)

(Morton 2000,IAU 標準。實作:`templates.air_to_vacuum`。)

天空成分(`sky_continuum.npy`、`sky_basis_*.npy`)與各 step 的產出皆以
**通道編號**索引,不帶波長標籤,因此不受此轉換影響;
`step03/wavelength.npy` 維持空氣波長,因為它描述的是 cube 本身。

**驗證**:Haro 11 (ID 1) 的加總光譜掃描,未轉換時得 z = 0.02025,
轉換後得 z = 0.02053,位移 2.8 × 10⁻⁴ 與理論值相符;
與文獻值 z = 0.0206 的差距由 105 km/s 降至 21 km/s(約 1/3 個 MUSE 光譜像素)。

## 5. 已知限制

**模板類型不含星爆星系。** 六條星系模板為 early-type、generic galaxy ×3、late-type、LRG,
無藍緻密星系或星爆星系。Haro 11 為極端藍緻密星爆星系,連續譜斜率與發射線等值寬度
均與這些模板有明顯差距。教授的處理方式:先以此建立可運作的 baseline,再以 PCA 補正殘差。

此缺口已在 Haro 11 (ID 1) 的加總光譜上量化(最佳解:模板 027 late-type,z = 0.02053):

| 項目 | 數值 |
|---|---|
| 源發射線所在通道 | 94 / 3801(2.5%) |
| 這些通道的 χ² 佔比 | **72.4%** |
| reduced χ²(全部) | 6534 |
| reduced χ²(排除發射線) | 1847 |

各線的 χ² 貢獻由大而小:Hα(6.3e6)、[O III] λ5007(5.3e6)、[O III] λ4959(2.1e6)、
Hβ(1.6e6)、[N II](1.0e6)、[S II] λ6716(1.0e6),其餘 < 0.2e6。
**所有譜線的殘差皆為正**,即模板全面低估發射線強度。

連續譜、天空連續譜與天光線的擬合均良好(絕大多數波長殘差在 ±2 以內),
紅移亦精確(殘差峰值落在 Hα 預測位置 0.3 Å = 13 km/s 之內)。
缺口**僅限於源的發射線強度**。

**光譜解析度不匹配。** SDSS 約 R ≈ 1500–2500;MUSE 為 R ≈ 1770(4800 Å)至 3590(9300 Å),
紅端 MUSE 較銳利。卷積只能展寬不能銳化,因此無法把模板提升到 MUSE 的解析度。
連續譜不受影響,發射線的線寬會失配。

## 5b. 待確認:星系模板之間可能不獨立

> **本節為觀察記錄,尚未經教授確認。** 量測結果是可重現的;對成因的解讀是推測,
> 在取得確認之前不應據以排除任何建模方式。

### 量測到的事實

在 Haro 11 (ID 1) 的加總光譜上,把 28 條模板(0–27)全部放進設計矩陣
(即 O = Σᵢ Aᵢ·Tᵢ 的線性組合形式)後,擬合全數失敗:

| 量測 | 數值 |
|---|---|
| 設計矩陣欄數 | 39(28 模板 + C_sky + 10 天光線) |
| `np.linalg.lstsq` 判定的秩 | **36** |
| 條件數 | 3.6 × 10¹² |
| 掃描結果 | 201 個 z 值全部回傳 NaN |

`utils.fit_chi2_coefficients` 內建 `rank < n_coeff` 檢查,於是拒絕求解。
作為對照,單一模板的設計矩陣(12 欄)秩為 12、條件數 7.0 × 10³;
僅含 23 條恆星模板的設計矩陣(34 欄)秩為 34、條件數 5.6 × 10⁴。

零空間的 3 個方向,其主要成分**全部落在模板 023–027**(5 條星系模板)上,
恆星模板的分量可忽略。單獨對這 5 條做 SVD:

| 奇異值 | 佔比 |
|---|---|
| 1.944 | 100% |
| 0.335 | 17.2% |
| 2.7 × 10⁻⁸ | ~0 |
| 2.3 × 10⁻⁸ | ~0 |
| 2.0 × 10⁻⁸ | ~0 |

第 3 個之後比第 2 個小約 7 個數量級。

這 5 個檔案的 header 共用同一組波長參數(`NAXIS1` = 4197、`COEFF0` = 3.544068),
且都帶有 `ECLASS`、`ECOEFF1`–`ECOEFF5` 欄位(數值均為 −999,未填)。

### 扣除天空子空間後的有效維度

以 Haro 11 (ID 1) 的加總光譜、z = 0.0206、svd basis,把 28 條模板各自投影到
天空子空間的正交補(u = t̃ − Q(Qᵀt̃)),再對 28 條 u 做 SVD:

| 奇異值序號 | 相對第一個 |
|---|---|
| 1–23 | 1.0 遞減至 4.7 × 10⁻³ |
| 24 | 7.8 × 10⁻⁶ |
| 25 | 4.4 × 10⁻⁶ |
| 26–28 | ≈ 2 × 10⁻¹² |

第 23 與第 24 之間落差約 600 倍,第 26 之後為數值零。
容差 10⁻⁶ 至 10⁻¹⁰ 下的有效秩為 **25/28**。

同一組模板另有一項量測:每條模板落在天空子空間外的比例
(‖u‖² / ‖t̃‖²)僅 **0.57 % – 3.62 %**。也就是說天空模型
(C_sky + 10 條 basis)已能解釋任一模板 96 % 以上的形狀,
可用於判別源是否存在的資訊只有其餘的百分之幾。

### 推測(待確認)

上述數值**可能**代表:模板 023–027 並非五條互相獨立的星系光譜,而是由一組低維
特徵譜(eigenspectra)重建出來的樣本;`ECLASS` 欄位的存在暗示它們可能對應
SDSS 星系分類序列上的不同位置。若此推測成立,則:

- 把這 5 條同時放入線性組合,可能不會提供多於 2 條的資訊;
- 教授信中的 "finding the right **combination** of object templates",
  **可能**是指「為每個源挑出合適的模板」而非「同時求解所有模板的權重」。

### 待請教教授的問題

1. O(p, λ) 的形式應為單一模板 `A·Tᵢ`,還是線性組合 `Σᵢ Aᵢ·Tᵢ`?
   信中的方程式為前者,但 "basis" 與 "combination" 的用詞指向後者。
2. 若採線性組合,是否應限制模板條數、或加入非負限制(NNLS)/正則化來處理病態?
3. 模板 023–027 的來源是否確為特徵譜重建?若是,應使用幾條為宜?

### 目前的處置

`step4_find_template.py` **只實作單一模板模式**。線性組合的程式路徑已移除:
它在現行模板集合下只會回傳 NaN,且任何可用的線性組合實作都必須另外處理
上述秩不足(模板裁減、截斷 SVD、ridge 正則化或 NNLS 擇一),
與已移除的版本不會相同。本節的量測數值即為該版本的完整紀錄。

選擇單一模板的理由是數值可解性,不是對建模方式的科學判斷。

**已驗證此選擇不影響本階段的結論**:六種 sky basis 在單一模板模式下,
全部給出相同的模板(027)與相同的紅移(z = 0.02053)。

## 6. 在模型中的角色

    D(p, λ)   = O(p, λ) + SkyC(p, λ) + SkyL(p, λ)
    O(p, λ)   = A · Tᵢ(λ / (1 + z))
    SkyC(p,λ) = s(p) · C_sky(λ)
    SkyL(p,λ) = Σₖ cₖ(p) · Lₖ(λ)

以 n(p, λ) = √STAT 加權,最小化

    χ² = Σ_λ [D(p,λ) − O(p,λ) − SkyC(p,λ) − SkyL(p,λ)]² / n(p,λ)²

參數性質決定求解方式:

| 參數 | 性質 | 求法 |
|---|---|---|
| A、s(p)、cₖ(p) | 線性 | 加權線性最小平方,一步求解 |
| z | 非線性 | 掃描 z 網格,逐點解線性問題後比較 χ² |
| i(模板編號) | 離散 | 逐條試 |

模板編號 i 與紅移 z 由**同一 segmentation ID 內所有 spaxel 的加總光譜**決定(高 S/N),
決定後對該源全部 spaxel 固定;逐 spaxel 只求解線性參數。

## 7. 紅移搜尋

### 7.1 目前的設計

均勻網格窮舉全域,不分粗細兩段。參數在 `step4_find_template.py` 的命令列選項:

    zmin  = 0.0        zmax = 0.06        zstep = 1e-5        →  6001 個格點

每個格點上,28 條模板同時紅移到 MUSE 波長格點並一次擬合;
z 與模板編號皆為窮舉,線性參數 A、s、cₖ 為解析解(見 §6 的表)。
37 個源全部掃完約 233 秒。

換算成物理量:

| 量 | 值 |
|---|---|
| zstep = 1e-5 | 3.0 km/s |
| 同上,在 6700 Å 的位移 | 0.067 Å = 0.054 個 MUSE 通道 |
| 1 個 MUSE 通道(1.25 Å)在 6700 Å | Δz = 1.87e-4 = 56 km/s |

**採用全域細掃而非「粗掃 + 局部精修」的理由是實作面**:兩段式需要視窗寬度、
邊界裁切、遮罩是否重算、以及假源必須複製同一套兩段程序;全域細掃只是一個參數值。
兩者在 37 個源上給出相同答案 34/37,三個分歧中兩個源於兩段式的視窗未裁切到
`[zmin, zmax]`,一個(ID 2)源於兩個相距 3795 km/s 而 Δχ² 僅差 0.111% 的等高峰。

### 7.2 精細度的物理下限

逐步收緊的三道限制:

    網格取樣      zstep 必須細於 1 個 MUSE 通道           →  Δz < 1.87e-4
    質心精度      σ_z ≈ (線寬 / λ) / √Δχ²,強源可遠低於一個通道
    波長定標      MUSE 定標殘差(典型 ~0.03 Å)為系統下限  →  Δz ≈ 4.5e-6 ≈ 1.3 km/s

第三項是真正的地板:低於它所量到的是儀器的定標誤差,不是天體的紅移。
本資料的 header 未提供波長定標的 QC 關鍵字,0.03 Å 為 MUSE 的公開典型值,
未在本資料上實測。

zstep = 1e-5(3.0 km/s)距地板有 2.3 倍餘裕。相對於實測的峰寬(§7.3)為
每個半高全寬取 60–120 點,屬過度取樣;此步長的選擇是留餘裕,不是解析度需求。

### 7.3 峰高與峰間距是兩個獨立的量

同一條 Δχ²(z) 曲線讀出兩件不同的事:

    峰高    Δχ²_best                     →  有沒有源(偵測顯著性)
    峰間距  Δχ²_best − Δχ²_次高峰        →  z 準不準(紅移可信度)

兩者不相關。強偵測可以配上完全未定的 z:模板為恆星時,Δχ² 由連續譜形狀主導,
而連續譜對小幅紅移不敏感,曲線因此呈現一片高度相近的峰。

單一參數的信賴區間判準為 Δχ² = 1(1σ)、3.84(95%)、6.63(99%);
本資料的 reduced χ² 約 3–5,形式化的間距應先除以該值再解讀。

Δχ²(z) 曲線在 241 個格點上有 37–60 個局部極大值。次峰的位置對應譜線誤認:

| 模板的 Hα 被放到 | 預測 Δz | Haro 11 實測 |
|---|---|---|
| [NII] 6549.9 | −0.00224 | −0.00225 |
| [NII] 6585.3 | +0.00315 | +0.00325 |
| [SII] 6718.3 | +0.02341 | +0.02400 |
| [SII] 6732.7 | +0.02560 | +0.02625 |

這是網格窮舉不可被局部優化法取代的原因。

### 7.4 未採用:FFT 互相關(未來可選項)

在對數波長下,紅移是純平移:

    ln λ_obs = ln λ_rest + ln(1 + z)

若資料與模板重採樣到均勻的 ln λ 格點,改變 z 等於把模板平移整數格。
此時 Δχ² 的分子退化為互相關 —— 因為殘差 r 與天空子空間正交:

    Qᵀr = Qᵀỹ − (QᵀQ)(Qᵀỹ) = 0            (QᵀQ = I)
    u·r = T̃·r − (QᵀT̃)·(Qᵀr) = T̃·r

分母同樣可拆成互相關:

    u·u = ‖T̃‖² − ‖QᵀT̃‖²
    ‖T̃‖²   = Σ_λ T(λ)² / σ(λ)²        T² 與 1/σ² 的互相關
    ‖QᵀT̃‖²  由 Q 的每一欄與 T 的互相關取得   (K+1 次)

一條模板的完整 Δχ²(z) 曲線只需 K+3 ≈ 13 次 FFT,成本 O(n log n)。

未採用的原因與前提:

| 項目 | 內容 |
|---|---|
| 前提 | MUSE 在 λ 均勻而非 ln λ,須重採樣 → 內插使雜訊相關,χ² 的定義隨之改變 |
| 前提 | r、σ 與 Q 的每一欄都須一併重採樣 |
| 前提 | NaN 遮罩與邊界須以補零處理 |
| 解析度 | 等於 ln λ 的格距,在 6700 Å 為 Δz ≈ 1.9e-4,仍需局部精修才能到次通道 |
| 效益 | step4 只跑 37 條加總光譜(全部 10 秒);step5 的 z 固定,不做搜尋 |

搜尋 z 不是計算瓶頸,因此本專案採用網格窮舉。
FFT 互相關列為未來若需大量重複搜尋(例如逐 spaxel 求速度場)時的選項。
